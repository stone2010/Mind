## 新增

### 真实费用与每对话费用

- DeepSeek 默认使用官方峰谷价格自动估算：
  - Flash：输入（缓存未命中）$0.15–0.30 / 输出 $0.60–1.20 每百万 tokens
  - V4 Pro：输入 $0.66–1.32 / 输出 $1.98–3.96 每百万 tokens
- 解析服务商返回的缓存命中/未命中 token，并按缓存命中价单独计算。
- 峰时窗口：工作日 09:00–12:00、14:00–18:00（北京时间）；其余为谷时。法定节假日暂按工作日计算。
- 对话标题栏实时显示“本对话 ≈ X 分”，按对话内所有聊天、压缩和记忆调用累计。
- 支持修改 USD→CNY 汇率；非 DeepSeek 模型可以在设置中单独填写峰谷输入/输出单价。
- 关闭用量记录后，不再写入新记录，也隐藏对话费用。

### 用户协议与隐私

- 新增用户协议和隐私说明，首次使用前显示确认门禁。
- 用户可在“设置 → 关于”中重新查看。
- 协议涵盖本地客户端、BYOK、第三方模型/GitHub/MCP 风险、AI 输出、数据备份、责任限制和赔偿。

### 数据导出与导入

- 设置 → 数据与备份：导出 JSON，包含对话、消息、项目、记忆和用量。
- 不包含 API Key、GitHub Token、连接器凭据和设置。
- 支持合并导入和覆盖导入；覆盖前会二次确认。
- 局域网自动同步尚未实现，可使用 JSON 备份配合 OneDrive、坚果云等同步盘手动迁移。

## 验证

- 本地 usage 实测：缓存命中 10、未命中 8、输出 42 tokens，DeepSeek 谷时约 0.02 分，峰时翻倍。
- 每对话费用在消息完成后实时刷新。
- 导出 JSON 已验证包含 1 个对话、2 条消息、1 条用量记录，且不包含测试 Key。
- 合并导入、覆盖导入均通过。
- 用户协议门禁可正常接受并持久化。
- `cargo test --lib` 8 个测试通过；`npm run build` 通过。
