## 长期记忆改进

- **自动记忆不再每轮都调用模型**：只有出现新的用户消息、且距上次提取超过 45 秒时才会提取，明显减少后台模型调用与费用；手动「从当前对话补记」不受限制。
- **默认改用「相关记忆」注入**：按当前问题挑最多 8 条相关记忆，比默认注入最近 24 条更省 token、噪音更少；仍可在设置里切回「最近记忆」。
- **记忆页重新整理**：开关、使用方式、统计、搜索、筛选、添加记忆放在一屏内更清晰的位置；类型 / 主题等高级字段收进「更多选项」，日常只需写一句自然语言。
- **手动添加去重**：与已有记忆近似的条目会直接复用，不再产生重复卡片（自动提取此前已支持）。
- **注入与补记体验**：对话标题栏保留记忆条数入口；侧边栏新增「记忆」导航并显示有效条数；失败原因仍会明确提示。
- **提取请求更兼容**：指令与对话内容拆分为 system + user 两条消息，避免只发 system 消息时部分 OpenAI 兼容服务返回异常。

## Android 手机端适配（对齐 DeepSeek 手机端习惯）

- 抽屉历史侧栏加入滑入动画；对话的「…」操作按钮常驻可见，不再依赖鼠标 hover。
- 触控尺寸调整：发送 / 停止按钮 36px、消息操作按钮 32px、抽屉对话行 40px、设置标签 36px。
- 移动端隐藏对话费用角标，标题区域更宽松；记忆与返回键仍可直接访问。
- 设置页横向分区标签会自动滚动到当前分区（从聊天页点记忆直接定位）。
- 设置与搜索弹层在手机宽度下重新排版；聊天内容左右留白与字号更贴近手机阅读。
- 全局禁用移动端点击高亮、输入框使用 16px 字号避免误缩放，保留系统返回键与 edge-to-edge 安全区域。

## 其他

- 新增 `MIND_DATA_DIR` 环境变量：测试 / 便携使用时可以显式指定本地数据目录（默认仍为系统应用数据目录）。
- 修复 Windows 开发时编辑器临时文件导致 Vite 文件监听崩溃（EBUSY）的问题。
- 版本升级到 0.1.3（Android versionCode 1003）。
