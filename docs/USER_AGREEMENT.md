# Mind 用户协议

版本：1.0  
更新日期：2026-11-17  
生效日期：2026-11-17

> 重要提示：Mind 是本地运行的 AI 客户端，不提供模型服务。AI 生成内容可能不准确，不构成法律、医疗、金融或其他专业建议。使用前请阅读本协议和《隐私说明》；如果你不同意，请停止使用并卸载 Mind。

## 1. 协议主体与接受

1.1 本协议是你与 Mind 项目维护者（以下简称“开发者”或“我们”）之间关于下载、安装和使用 Mind 软件及相关文档的协议。

1.2 你点击“同意并继续”、安装、复制或使用 Mind，即表示你已阅读、理解并同意本协议及《隐私说明》。如果你不同意，请勿使用。

1.3 你应具备与你的行为相适应的民事行为能力。若你不具备，应在监护人陪同下阅读并决定是否使用。

## 2. 服务说明

2.1 Mind 是一个本地运行的桌面客户端，提供聊天界面、模型 API 调用、联网搜索、记忆、连接器、GitHub 读取、用量统计和可视化等功能。

2.2 Mind 不提供模型推理服务，也不销售模型额度。你需要自行向 DeepSeek 或其他模型服务商申请 API Key，并遵守其服务条款、价格、限额和内容政策。

2.3 Mind 本身不收取订阅费或服务费；你向第三方服务商支付的费用由其直接向你收取。开发者不对第三方服务的价格、可用性、输出质量或计费结果作出承诺。

2.4 你理解并同意，模型服务、GitHub、MCP 插件等第三方服务可能随时变更、限流、停机或调整价格，Mind 无法保证这些服务始终可用或保持兼容。

## 3. 密钥与账号安全

3.1 你的 API Key、GitHub Token 等凭据由你自行获取和保管。Mind 会尝试将它们保存到操作系统的凭据存储中，但你有责任保护设备、系统账户和凭据安全。

3.2 你不得使用他人的密钥、共享密钥，或绕过第三方服务的安全、计费或访问限制。

3.3 因你的设备被入侵、凭据泄露、误操作或第三方服务安全事件造成的损失，由你自行承担；但法律另有强制性规定的除外。

## 4. 用户内容与授权

4.1 你对你输入的内容、上传的文件、通过连接器读取的数据以及由这些内容产生的输出负责。你应确保你拥有处理这些内容的合法权利。

4.2 为向你提供功能，Mind 会在你的设备上处理并将必要内容发送给你选择的模型服务商、GitHub 或 MCP 插件。你应确认这些接收方和数据处理方式符合你的要求。

4.3 你授予开发者仅为运行、维护和改进 Mind 所必需的最小权限；Mind 不会将你的聊天记录或密钥上传到开发者自己的服务器。具体数据处理方式见《隐私说明》。

## 5. 第三方服务与工具

5.1 GitHub 连接、模型 API、MCP 插件等由第三方提供或由你自行配置。第三方服务有自己的条款和隐私政策，你应自行阅读并遵守。

5.2 MCP 插件是可以在你的电脑上运行的程序，可能读取文件、访问网络或执行其他操作。你应只安装可信来源的插件，并逐次确认工具调用参数。

5.3 GitHub 工具目前为只读操作；即便如此，仓库内容、Issue、PR 和文件仍可能包含敏感信息。你应在授权前确认目标仓库和参数。

5.4 开发者不对第三方插件、第三方服务或你自行配置的命令造成的损失承担责任；但法律另有强制性规定的除外。

## 6. AI 输出与专业建议

6.1 AI 输出可能不准确、不完整、过时或具有误导性。你应在依赖输出前自行核实，尤其是法律、医疗、金融、安全、税务和其他专业领域。

6.2 Mind 不构成律师事务所、医疗机构、金融机构、投资顾问或其他专业服务机构，也不与你建立任何专业服务关系。

6.3 你不得将 AI 输出作为唯一依据作出可能对他人产生重大影响的决定。

## 7. 使用规范

你不得利用 Mind：

- 违反法律法规、公序良俗或第三方服务条款；

- 绕过第三方服务的计费、访问控制、安全机制或速率限制；

开发者有权在合理范围内拒绝服务、限制功能或停止分发，但应遵守适用法律和平台规则。

8.2 你有责任自行备份重要数据。设备损坏、系统重装、误删除、数据库损坏、第三方同步失败或应用卸载可能导致数据丢失；开发者不承诺数据永不丢失。
