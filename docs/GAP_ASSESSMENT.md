# Mind 与 GPT 网页端 能力对比评估与修改策略

> 本文档为本次开发（`D:\claude code\mind-dev` 副本）的评审与交付说明。
> 目标：让 Mind 在配置好 DeepSeek 密钥后，能力对齐 GPT 网页端，且对用户友好。

## 一、现状评估：Mind 相比 GPT 网页端的差距

| 维度 | GPT 网页端 | Mind 原状 | 本次处理 |
|---|---|---|---|
| 主动澄清（信息不足时反问） | 强，会列选项/追问 | 无 | ✅ P0 已补：`ask` 代码块 + 可点击选项/填空卡片 |
| 数据可视化 | 图表、流程图 | 有 Mermaid/图表但被动 | ✅ P1 已补：系统提示词让 AI 主动出图 |
| 跨对话长期记忆 | 有（ChatGPT memory） | 有机制但**默认关闭** | ✅ P0 已补：默认开启 + 提升注入上限 |
| 深度推理分级 | 有（think 模式） | 有 thinking 开关 | ✅ P0 已补：提示词路由（思考→复杂风格） |
| 简短口语聊天 | 有 casual 风格 | 无 | ✅ P1 已补：聊天娱乐模式（默认隐藏） |

## 二、本次交付的修改（按优先级）

### P0 — 基础对齐
1. **跨对话长期记忆默认开启**
   - `autoMemory`、`longTermMemory` 默认 `true`，回复后自动提取持久事实。
   - 注入上限从 12 条/200 字 → 24 条/上限随上下文（约 1/4 预算），让旧对话事实仍能浮现。
   - 记忆注入措辞改为「自然融入、不让用户察觉在回忆」。

2. **系统提示词复杂度路由**（学习 Claude 提示词写法，**身份不变**）
   - 始终自称「Mind」，不切换为其他模型。
   - 深度思考开启 → 复杂任务风格（结构化推理、主动可视化、可先确认前提）。
   - 普通模式 → 简洁直接风格。
   - 联网搜索 / 工具可用时，追加对应使用协议。

3. **主动澄清协议**
   - 信息不足时最多 3 问，选择题（A/B/C）或填空题（```` ```ask ```` Q1–Q3）。
   - 前端把 `ask` 块渲染成可点击选项 + 填空输入框，一键提交。

### P1 — 体验增强
4. **聊天娱乐模式**
   - 默认完全隐藏，需在 设置→通用→聊天娱乐模式 打开开关才出现。
   - 首次开启强制弹窗确认「纯娱乐、省 token、不适合生产力」。
   - 开启后聊天框出现「聊天」按钮，回复变为 1–4 句口语化。

5. **主动可视化**
   - 比较/趋势/占比/流程时主动出 Mermaid 或 chart 图，且无真实数据不编造。

## 三、用户操作指引

1. 双击桌面「Mind - beta」快捷方式启动开发版。
2. 首次运行：同意协议 → 填入 DeepSeek API Key（平台可获取）→ 完成引导。
3. 跨对话记忆已默认开启；想关：设置 → 记忆 → 关闭「自动记忆 / 在对话中使用记忆」。
4. 复杂任务勾选「深度思考」；日常对话保持普通模式即可（自动简洁）。
5. 想玩简短聊天：设置 → 通用 → 打开「聊天娱乐模式」→ 聊天框出现「聊天」按钮。
