# Mind 隐私说明

版本：1.1  
更新日期：2026-11-21  
生效日期：2026-11-17

Mind 是一个本地优先的 Windows / Android 客户端。本说明解释 Mind 处理哪些数据、数据去哪里，以及你可以如何控制和删除数据。

## 1. 我们是谁

Mind 由项目维护者开发和维护。Mind 没有自己的模型服务器，也不要求你注册 Mind 账号。你使用自己的模型 API Key、GitHub Token 和本地插件。

## 2. Mind 在本机保存什么

Mind 会在本机保存：

- 对话标题、消息内容、推理内容、附件元数据和附件文本；
- 项目、记忆、设置和连接器配置；
- 工具调用记录（连接器名称、工具名、参数和结果摘要）；
- 模型返回的 token 用量以及你填写的价格设置；
- 应用日志（如有）和本地数据库文件。

默认位置：

- Windows 数据库：`%APPDATA%\com.mind.desktop\mind.db`
- Android 数据库：应用私有数据目录（`/data/data/com.mind.desktop/`，其他应用无法读取）
- Windows WebView 缓存：`%LOCALAPPDATA%\com.mind.desktop\EBWebView`
- Windows 凭据：Windows Credential Manager
- Android 凭据：Android Keystore 加密后的密文，保存在应用私有 SharedPreferences 中

## 3. 密钥如何处理

- 模型 API Key 和 GitHub Token 由你提供；
- Windows：Mind 尝试将它们保存到 Windows Credential Manager，而不是 SQLite、设置文件或日志；
- Android：Mind 使用 Android Keystore 中不可导出的 AES-256-GCM 密钥加密后，把密文保存在应用私有目录；密钥本身不离开系统密钥库，明文只在应用运行内存中出现；备份文件不包含这些密钥；
- Mind 不会把密钥上传到开发者自己的服务器；
- 当你发起请求时，密钥会由 Mind 直接用于连接你选择的模型服务或 GitHub。

如果你在第三方 MCP 插件中配置了环境变量或令牌，相关数据由插件自行处理。请只安装可信插件。

## 4. 数据会发送到哪里

Mind 不通过开发者服务器中转请求。根据你启用的功能，数据可能发送给：

- **模型服务商**（例如 DeepSeek）：你发送的消息、附件文本、记忆、上下文摘要、工具定义和工具结果；
- **GitHub**：你批准的工具调用参数（仓库名、Issue/PR 编号、文件路径等），以及 GitHub 返回的数据；
- **本地 MCP 插件**：你在插件中查询或操作的数据；插件可能访问网络；
- **你自行配置的其他 OpenAI 兼容服务**。

这些第三方服务有自己的隐私政策和数据处理规则。开发者无法控制它们如何存储、使用或保留数据。若你不希望某些内容发送给第三方，请不要输入、上传或调用相关工具。

## 5. 联网搜索

使用 DeepSeek 联网搜索时，搜索由 DeepSeek 服务端执行；Mind 会把搜索查询、结果来源和必要的上下文发送给 DeepSeek。搜索来源卡片保存在本地，并可能随对话历史发送给模型。

## 6. 用量与费用数据

Mind 保存服务商返回的 token 用量（输入、输出、缓存命中和未命中、总计）以及你填写的单价、汇率和峰谷设置。它们只用于本地用量看板和费用估算，不会上传到开发者服务器。

费用为估算值；实际账单以服务商为准。

## 7. 分析、遥测和广告

Mind 当前不包含开发者运营的分析、遥测、广告或用户画像服务，也不会主动向开发者服务器发送使用数据。若未来加入此类功能，会更新本说明并取得必要同意。

## 8. 数据导出、同步和删除

- 你可以在“设置 → 数据与备份”中导出 JSON 备份；
- 备份包含对话、消息、项目、记忆和用量，不包含 API Key、GitHub Token 或设置；
- 你可以关闭用量记录、清除用量记录、删除对话或删除本地数据目录；
- 当前没有云同步；把备份放入 OneDrive、坚果云等同步盘属于你自行选择的第三方处理方式。

卸载 Mind 不一定会自动删除数据库和 WebView 缓存。如需彻底删除，请关闭应用后删除上面的本地目录，并删除 Windows Credential Manager 中的 `provider:<id>` 和 `github:main` 条目；Android 卸载应用会同时删除应用私有目录（含加密凭据）。

## 9. 安全

Mind 使用本机 SQLite、系统凭据管理器和传输层加密连接第三方服务。Android 上，API Key 与 GitHub Token 使用 Android Keystore 支持的 AES-256-GCM 加密存储，且应用关闭了系统自动备份，避免凭据或聊天数据被同步到云端。但没有任何系统能保证绝对安全。你应保护设备登录账户、及时更新系统和浏览器运行时，并只安装可信插件。

## 10. 儿童

Mind 不是专门面向儿童的产品。未满 14 周岁的儿童应在监护人同意和指导下使用。监护人应避免儿童输入敏感个人信息。
